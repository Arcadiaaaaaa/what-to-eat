# 今天吃什么 🍚

一个帮你决定「今天吃什么」的小工具：按**早餐 / 午餐 / 晚餐**管理常吃的餐品、饮品与拼菜窗口，一键随机推荐，三种模式可选——**餐品 + 饮品**、**仅餐品**、**仅饮品**。

纯静态单页应用，零依赖、无后端，数据保存在浏览器 localStorage，可直接部署到个人作品集服务器。

## 功能

### 推荐页（默认视图）
- 早 / 午 / 晚餐段切换，三种推荐模式，随机结果展示单价与合计
- **偏好加权随机**（算法见 `meal-random.js`，含 18 项确定性单测）：
  - 结果卡片上对每个条目 / 窗口可点 👍（权重 ×1.25）/ 👎（×0.4，可累积）/ 🚫 忌口（不再出现），每条结果每槽只计一票，改选先撤销
  - 权重随时间向中性恢复（偏离 30 天半衰）；10% 均匀探索保底；上轮抽中的实体软降权 ×0.5（按餐段+槽位）
  - 结果上实时显示每个候选的当前权重与抽取概率
- **价格区间**（💰 限定价格）：按结果价格过滤——仅餐品/仅饮品按单价，组合模式按餐品+饮品合计；未标价条目不参与；先过滤后加权
- **结果微调**：随机结果不合适可当场换——窗口里每道菜可 ⇄ 换成同窗口其他菜，饮品 / 单点可整槽换；换过自动重算价格并标记「已微调」
- **菜品级反馈**：每道菜可单独 👍 / 👎（权重机制与实体级一致，窗口抽菜时按菜品权重抽取）
- **结果持久化与历史**：每次随机自动记录（含微调与反馈），刷新 / 重开页面恢复上次结果，可继续微调和补投反馈；下方「最近的随机记录」可回看（跨页面记录不可撤销，可在设置恢复默认）

### 设置页（`#/settings`）
- **偏好与忌口**：所有被 👍/👎/🚫 影响过的条目集中展示（反馈权重、随时间恢复的当前权重、忌口状态），一键恢复默认
- **普通条目**：名称、价格（可留空）、类别、适用餐段（可多选），支持编辑
- **拼菜窗口**：自选窗口录成一个「窗口」——窗口名、适用餐段、拼法（双拼 / 三拼 / 四拼可多选）、每道菜的价格，窗口和菜品均支持编辑
  - 随机时，窗口与普通餐品一起参与「餐品」抽取；抽中窗口则从其菜品中不重复地随机拼出对应份数
  - 定价两种模式：**一口价**（按拼数，如双拼 ¥12，可选填）或**按菜价合计**（未填一口价时）
- **AI 批量导入**：内置「菜单转 JSON」提示词（一键复制）。拍菜单照片发给任意 AI 并附上提示词，把 AI 输出的 JSON 粘贴导入即可批量录入
  - 导入解析容错：自动剥离 ```json 代码围栏；兼容中文餐段（早餐/午/晚/全天）、中文拼法（双拼/三拼）、带单位价格（"12元"）
- 删除均为点两次确认；数据导出 / 从文件导入（与 AI 粘贴导入共用同一套容错解析）

## 本地运行

直接双击 `index.html` 打开，或：

```bash
cd 是啊吃什么
python3 -m http.server 8080
# 访问 http://localhost:8080
```

## 部署

纯静态文件，任意静态托管可直接上线（已内置 PWA，支持加到主屏与离线打开）。推荐主线路为腾讯云 EdgeOne Pages（国内直连快），另备 Cloudflare Pages / 自有服务器方案，完整步骤见 [DEPLOY.md](DEPLOY.md)。

## 数据说明

所有数据仅保存在当前浏览器的 localStorage（键名 `what-to-eat-data-v1`，内部版本 v2），不上传服务器。
清除浏览器数据前请先在设置页「导出数据」备份。

## 路线图

- **v0.1** ✅ MVP：三餐段、三种模式随机推荐、导入导出
- **v0.2** ✅ 设置独立页面；拼菜窗口（双拼 / 三拼 / 四拼 + 一口价 / 合计两种定价）
- **v0.3** ✅ 编辑功能（条目 / 窗口 / 菜品）；AI 批量导入（菜单转 JSON 提示词 + 粘贴导入 + 容错解析）
- **v0.4** ✅ 按价格区间推荐（组合按合计；先过滤后抽样）
- **v0.5** ✅ 偏好反馈加权随机（👍/👎/🚫 + 时间衰减 + ε 探索 + 软防连抽；独立算法模块 meal-random.js + node 单测；设置页偏好与忌口管理）
- **v0.6** ✅ 结果微调（换菜 / 换饮品）+ 菜品级反馈与加权抽菜 + 结果持久化与最近记录
- **视觉** ✅ 「食堂小票」视觉方案（设计系统「今天吃什么」）：暖色纸感、宋体标题、等宽数字、撕线与锯齿小票、「吃」字印章标志；白天 / 夜宵两套主题跟随系统；出票、盖章、按键下沉等动效，尊重「减少动态效果」
- **v0.7** 饮食记录统计（吃了什么 / 花了多少钱，基于 v0.6 的历史结构扩展）
- **v0.8** 企业微信推送每日推荐（需引入少量后端或云函数）、多设备云同步
