# 今天吃什么 🍚

一个帮你决定「今天吃什么」的小工具：按**早餐 / 午餐 / 晚餐**管理常吃的餐品与饮品，一键随机推荐，三种模式可选——**餐品 + 饮品**、**仅餐品**、**仅饮品**。

当前为 v0.1 MVP：纯静态单页应用，零依赖、无后端，数据保存在浏览器 localStorage，可直接部署到个人作品集服务器。

## 功能

- 按早 / 午 / 晚三个餐段管理条目，一条条目可同时属于多个餐段（如「可乐」适用于午 + 晚）
- 录入名称、价格（价格可留空）、类别（餐品 / 饮品）
- 三种推荐模式随机推荐，展示单价与合计；同一槽位不会连续两次抽中同一个
- 内置示例数据，一键体验
- 数据导出 / 导入（JSON），换设备、清缓存前可备份

## 本地运行

直接双击 `index.html` 打开，或：

```bash
cd 是啊吃什么
python3 -m http.server 8080
# 访问 http://localhost:8080
```

## 部署

纯静态文件，把整个目录上传到作品集服务器即可。nginx 示例：

```nginx
server {
    # ... 已有配置 ...
    location /what-to-eat/ {
        alias /var/www/what-to-eat/;
        index index.html;
    }
}
```

也可以直接放 GitHub Pages / Vercel / Netlify 等任意静态托管。

## 数据说明

所有数据仅保存在当前浏览器的 localStorage（键名 `what-to-eat-data-v1`），不上传服务器。
清除浏览器数据前请先点「导出数据」备份。
