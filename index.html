        AI 批量导入

        把菜单拍照发给任意 AI，附上下方提示词，再将 AI 输出的 JSON 粘贴到下面即可批量导入

        菜单转 JSON 提示词 
        你是菜单数字化助手。请把用户提供的菜单照片或文字，整理成 JSON，要求：

1. 只输出 JSON（可用 ```json 代码块包裹），不要输出任何解释或多余文字。
2. 顶层结构：{"items": [...], "windows": [...]}，某一类没有就给空数组。
3. items 是单点的餐品 / 饮品，每个对象包含：
   - name：名称（必填）
   - price：单价，数字，单位元；菜单没写就给 null
   - type："food"（餐品）或 "drink"（饮品，粥、汤、豆浆等也按 drink）
   - meals：适用餐段数组，取值 "breakfast" / "lunch" / "dinner"，对应早餐 / 午餐 / 晚餐；菜单没说明就按常理判断
4. windows 是可以自选组合、双拼 / 三拼的窗口（自选快餐、称重菜、麻辣烫自选等），每个对象包含：
   - name：窗口名称
   - meals：同上
   - pickOptions：支持的拼法，如 [2, 3] 表示双拼、三拼
   - fixedPrices：可选，按拼数的一口价，如 {"2": 12, "3": 15}；菜单没写就省略
   - dishes：窗口内的菜品数组，每道菜 {"name": ..., "price": ...}，价格没写给 null
5. 不确定就不要编造，宁可省略；合并明显重复的条目。

        数据保存在当前浏览器本地（localStorage），不会上传 · v0.6
